# 京都暮色：符卡夜行

基于京都黄昏 ASCII 字符场景的单文件网页弹幕射击游戏。

## 在线游玩

部署 GitHub Pages 后：`https://kinster-123.github.io/kyoto-dusk/`

## 操作

- WASD / 方向键：移动
- Shift：低速精确移动
- Z / 空格：射击
- X / C：清屏符咒
- P：暂停
- 手机：拖动角色移动，触屏按钮使用符咒

## 部署

GitHub 仓库 Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save。

游戏使用内嵌 CSS 和 JavaScript，无需构建工具。

背景为原创程序化 ASCII 风格京都场景，灵感参考 ascii.rest/kyoto-dusk/；非原站图片资源复制。
